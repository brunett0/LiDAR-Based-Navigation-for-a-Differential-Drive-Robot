# LiDAR-Based-Navigation-for-a-Differential-Drive-Robot
LiDAR-Based Navigation for a Differential Drive Robot. A distributed Python/MATLAB framework for autonomous robotics on Raspberry Pi 4. Features a hybrid EKF-ICP localization system with Mahalanobis gating to solve the aperture problem, A* path planning with smoothing, and a real-time UDP-based stop-and-go safety routine.


###ITA

Il presente lavoro di tesi documenta la progettazione, l'implementazione e la validazione sperimentale di un'architettura hardware e software integrata e distribuita per la navigazione autonoma di un veicolo robotico mobile a trazione differenziale. L'infrastruttura si basa su un paradigma client-server operante in tempo reale tramite il protocollo di rete UDP a bassa latenza, strutturato per disaccoppiare il controllo embedded a basso livello — eseguito su una Single Board Computer Raspberry Pi 4 in linguaggio Python 3 — dall'elaborazione algoritmica ad alto livello, centralizzata in ambiente MATLAB su una stazione di controllo remota.

Sul fronte hardware, l'elaborato descrive la calibrazione cinematica della piattaforma e la riconfigurazione a basso livello del clock della UART del sistema operativo per consentire la comunicazione stabile con un sensore LiDAR omnidirezionale a tempo di volo diretto (D-ToF). La pipeline software di bordo sfrutta la programmazione asincrona e non bloccante per parallelizzare l'acquisizione dei dati laser e l'attuazione dei motori tramite modulazione PWM, azzerando i ritardi di sfasamento temporale. Per superare la degradazione geometrica delle scansioni indotta dal movimento, viene adottata e ottimizzata una strategia di navigazione discreta di tipo Stop \& Go.

Il nucleo algoritmico affronta il problema della localizzazione e della mappatura simultanea. Al fine di mitigare la divergenza cumulativa della deriva odometrica e garantire la sostenibilità computazionale sulla piattaforma embedded, l'approccio EKF-SLAM completo viene impiegato esclusivamente nella prima macro-fase progettuale legata alla mappatura ed esplorazione dell'ambiente ignoto. Una volta generata e validata la mappa a griglia occupazionale statica, il paradosso della SLAM viene rimosso: nella successiva fase di navigazione autonoma, il framework software passa a una logica di localizzazione e tracking puro su mappa nota, disaccoppiando l'algoritmo di corrispondenza geometrica dall'espansione del vettore di stato del filtro probabilistico. All'interno di questo scenario di navigazione, viene implementata un'architettura di stima ibrida in cui coesistono il Filtro di Kalman Esteso (EKF) e l'algoritmo geometrico Iterative Closest Point (ICP). Questa fusione sensoristica viene governata da una logica di gating statistico basata sulla Distanza di Mahalanobis con distribuzione Chi-Quadro ($\chi^2$), specificamente progettata per identificare i massimi locali equiprobabili derivanti da ambienti simmetrici e neutralizzare l'effetto di scivolamento longitudinale tipico del problema dell'apertura (Aperture Problem). La pianificazione della traiettoria globale ottimale è infine affidata all'algoritmo A$^*$, integrato con una routine di Line-of-Sight Path Smoothing per la minimizzazione delle rotazioni fisiche, e protetto da un modulo reattivo di arresto di emergenza basato su un cono di sicurezza frontale monitorato in tempo di volo.

##ENG

This thesis documents the design, implementation, and experimental validation of an integrated and distributed hardware and software architecture for the autonomous navigation of a differential drive mobile robotic vehicle. The infrastructure is based on a real-time client-server paradigm operating over a low-latency UDP network protocol, structured to decouple low-level embedded control — executed on a Raspberry Pi 4 Single Board Computer using Python 3 — from high-level algorithmic processing centralized within a MATLAB environment on a remote control station.
On the hardware side, this work describes the kinematic calibration of the platform and the low-level reconfiguration of the operating system's UART clock to enable stable communication with an omnidirectional Direct Time-of-Flight (D-ToF) LiDAR sensor. The on-board software pipeline leverages asynchronous and non-blocking programming to parallelize laser data acquisition and motor actuation via PWM modulation, eliminating phase lag and timing delays. To overcome motion-induced geometric scan distortion (motion skewing), a discrete Stop and Go navigation strategy is adopted and optimized.
The algorithmic core addresses the problem of simultaneous localization and mapping. In order to mitigate the cumulative drift of odometry and ensure computational sustainability on the embedded platform, the full EKF-SLAM approach is employed exclusively during the initial design macro-phase dedicated to mapping and exploring the unknown environment. Once the static occupancy grid map is generated and validated, the SLAM paradox is resolved: in the subsequent autonomous navigation phase, the software framework transitions to a pure localization and tracking logic on a known map, decoupling the geometric matching algorithm from the expansion of the probabilistic filter's state vector.
Within this navigation scenario, a hybrid estimation architecture is implemented where the Extended Kalman Filter (EKF) and the geometric Iterative Closest Point (ICP) algorithm coexist. This sensor fusion is governed by a statistical gating logic based on the Mahalanobis Distance with a Chi-Squared distribution, specifically designed to identify equiprobable local maxima arising from symmetrical environments and neutralize the longitudinal slip effect typical of the Aperture Problem. Optimal global path planning is ultimately entrusted to the A* algorithm, integrated with a Line-of-Sight Path Smoothing routine to minimize physical rotations, and protected by a reactive emergency stop module based on a time-of-flight monitored forward safety cone.
