# LiDAR-Based-Navigation-for-a-Differential-Drive-Robot
LiDAR-Based Navigation for a Differential Drive Robot. A distributed Python/MATLAB framework for autonomous robotics on Raspberry Pi 4. Features a hybrid EKF-ICP localization system with Mahalanobis gating to solve the aperture problem, A* path planning with smoothing, and a real-time UDP-based stop-and-go safety routine.
